Blocking launch checklist

  • Backend availability: deploy or start the target backend, then record its base URL, health check, and API version.
  • Production payment: complete a controlled Paystack payment and prove initiate → redirect → webhook → PAID → order confirmation.
  • Course enrollment: complete the OTP + course payment path and prove enrollment/access plus the customer email.
  • Fix checkout validation: do not allow paid delivery until config is loaded; send or remove first name, last name, and order note; enforce phone and state where labelled required.
  • Cart finalisation: prove that a paid order cannot leave a re-orderable stale cart and that server pricing is shown consistently.
  • Quality gates: make pnpm lint, pnpm build, and the relevant Playwright suite pass in a clean environment.
  • Production configuration: set NEXT_PUBLIC_API_URL, backend CORS origin(s), Paystack callback/webhook and secret, database backups, OTP/email provider, and error monitoring.
